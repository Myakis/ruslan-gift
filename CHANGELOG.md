## [Unreleased]

### Added
- `scripts/build_and_run.sh` — сборка, установка в `/Applications` и запуск
  одной командой под Apple ID того, кто запускает (Team ID берётся из
  сертификата, App Group выводится из него при сборке).
- Кольцо прогресса дня в иконке меню-бара (вместо таймера) и крупная кнопка
  «Начать день» / «Завершить день» в меню; завершение — удержанием.
- Синхронизация времени начала и окончания дня с Wplan (`WorkTimeEventsForDate`):
  виджет показывает верное время, даже если день начат или завершён на сайте.
- Автоматическое обновление хэшей GraphQL-запросов: при `PersistedQueryNotFound`
  приложение само открывает Wplan во встроенном браузере и перехватывает
  актуальные хэши. Ручной вариант — Настройки → «Хэши запросов».
- Автосброс состояния дня («Сбросить состояние дня» в Настройках и кнопка
  прямо в виджете) — позволяет перезапустить цикл старт/финиш в тот же день,
  не дожидаясь полуночи.
- Виджет: отдельные состояния «День завершён», «Нет данных» и «Выходной»
  (по расписанию рабочих дней) вместо неверной подписи или тревожного
  красного цвета.
- Мгновенное обновление виджета сразу после автоматического клика — не
  нужно ждать периодического обновления.
- MIT-лицензия.

### Changed
- Подпись без провижининг-профиля: App Group переименована в
  `8W787APH48.com.wplanwidget.app`. Сборка больше не перестаёт запускаться
  через 7 дней. При обновлении один раз сбрасываются расписание и сохранённые
  данные виджета (логин в Keychain сохраняется).
- Bundle ID и App Group переименованы с `ru.itmo.wplanwidget` на
  `com.wplanwidget.app`.
- Длительность рабочего дня в широком виджете считается из реального
  расписания, а не захардкожена на 8 часов.

## [v1.2.0-widget] — 2026-09-07

Первый релиз нативной Swift/SwiftUI версии Wplan Widget — замена старой
Electron-реализации. Меню-бар агент + виджет (кольцо дня, VPN-статус),
автоклик старта/финиша по расписанию, вход по логину/паролю с
Keychain-хранением.
